# ❄️ HibikiOS Rice — Ice Glass Wayland Environment

Собранная с нуля кастомная десктоп-оболочка **Hibiki UI** поверх тайлингового Wayland-композитора **Niri** на **Arch Linux**. Выполнена в едином стиле полупрозрачного морозного льда (`#ad11161f`) с тонкой белой фаской (`#aaffffff`) и плавными 165 FPS анимациями.

---

## ✨ Ключевые фишки

* **Трёхсекционный ледяной верхний бар (`shell.qml` + `GlassIsland.qml`):**
  * Живой индикатор воркспейсов и активного окна Niri;
  * Центральный остров часов и даты с открытием панели управления;
  * Правые линзы управления: переключение раскладки (`EN/RU`), поповеры Wi-Fi и звука, мониторинг CPU/GPU и центр уведомлений.
* **Выпадающие поповеры из бара (`BarPopovers.qml`):**
  * **Wi-Fi:** сканирование сетей, уровень сигнала, быстрое подключение и ввод пароля для новых точек доступа;
  * **Быстрый звук:** 165 FPS ползунки громкости и микрофона + переключение между устройствами вывода и ввода.
* **Центральная панель управления (`ControlCenter.qml`):**
  * Горизонтальный слайдинг вкладок (*Основное / Звук / Система*) со скользящей ледяной капсулой;
  * **Плеер в стиле One UI 9 (`OneUiPlayer.qml`):** фон из обложки трека, живой волновой прогресс-бар (`Squiggly Seekbar`) с плавным затуханием волны на паузе и бегунок перемотки;
  * **Лента обоев 16:9 (`TabMain.qml`):** скруглённые превью с предзагрузкой в буфер, прокруткой колёсиком мыши и живыми переходами через `awww`.
* **Фоновый аудио-эквалайзер и караоке-текст (`CavaVisualizer.qml` + `lyrics.py`):**
  * 4 режима отрисовки (`Столбики`, `Волна`, `Зеркало`, `Кольцо`) с умным сном при паузе музыки (0% нагрузки на GPU в простое);
  * Автоматический поиск синхронизированных `.lrc` текстов через `lrclib.net` с локальным кэшированием и масштабированием таймкодов под `slowed + reverb` / `nightcore` версии.
* **Кастомный центр уведомлений и тосты (`NotificationCenter.qml`):**
  * Полная замена `swaync` на встроенном D-Bus сервере Quickshell;
  * Полновысотная правая шторка со слайд-анимацией, режимом «Тихий», мини-плеером и эффектом растворения карточек в облако ледяных частиц при очистке;
  * Полупрозрачные всплывающие тосты с тающей ледяной полоской прогресса.

## 📦 Зависимости (Arch Linux)

```bash
sudo pacman -S niri pipewire pipewire-pulse wireplumber playerctl networkmanager bluez bluez-utils python cava
paru -S quickshell awww ttf-jetbrains-mono-nerd inter-font
```

---

## 🚀 Быстрая установка

```bash
git clone git@github.com:d1masik12/HibikiOS-rice.git ~/hibiki-dotfiles
cp -r ~/hibiki-dotfiles/.config/quickshell ~/.config/
cp -r ~/hibiki-dotfiles/.config/niri ~/.config/
chmod +x ~/.config/quickshell/*.py ~/.config/quickshell/*.sh
```

Перезапуск оболочки:
```fish
pkill -9 quickshell; sleep 0.3; quickshell &
```

## 📁 Структура репозитория

```text
.config/
├── niri/
│   └── config.kdl              # Конфиг композитора Niri (хоткеи, правила слоёв, мониторы)
└── quickshell/
    ├── shell.qml               # Верхний бар из 3 стеклянных островов
    ├── HibikiState.qml         # Единый синглтон состояния, MPRIS и D-Bus NotificationServer
    ├── GlassIsland.qml         # Базовый компонент ледяной линзы
    ├── ControlCenter.qml       # Центральная панель управления со слайдингом вкладок
    ├── TabMain.qml             # Плеер One UI 9, быстрые тайлы и лента обоев 16:9
    ├── TabAudio.qml            # Детальный микшер и выбор аудиоустройств
    ├── TabPerf.qml             # Кольца нагрузки CPU / GPU / RAM / SSD
    ├── OneUiPlayer.qml         # Виджет плеера с волновым прогресс-баром
    ├── BarPopovers.qml         # Выпадающие мини-окна Wi-Fi и звука из верхнего бара
    ├── NotificationCenter.qml  # Шторка уведомлений с частицами и всплывающие тосты
    ├── CavaVisualizer.qml      # Аудио-визуализатор поверх обоев и караоке-оверлей
    ├── lyrics.py               # Парсер синхронизированных текстов с поддержкой slowed/reverb
    ├── audio_devs.py           # Получение устройств PipeWire/PulseAudio
    ├── wifi_scan.py            # Сканер сетей NetworkManager
    └── poll.sh                 # Фоновый сборщик системных метрик
```
